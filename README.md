GymApp

En enkel console-applikation i C# för att logga träning.

Funktioner just nu
Lägga till övningar
Starta träningspass
Logga sets (reps + vikt)
Spara data i JSON
Visa träningshistorik
Struktur

Projektet är uppdelat i:

Models – dataklasser (Exercise, WorkoutSession osv)
Services – logik (StorageService, WorkoutService)
GymApplication – meny och användarflöde
Hur man kör
Klona projektet
Öppna i Visual Studio
Kör programmet (F5)
Status

Projektet är under utveckling.
Fokus just nu är att bygga struktur och grundfunktionalitet.
